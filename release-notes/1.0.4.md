# 极客译读 1.0.4

## 新增

- **华为账号一键登录**：登录页接入华为 LoginPanel（脱敏手机号展示 + 一键登录），支持「其他方式登录」切换
- **头像裁剪编辑器**：选择头像后可裁剪/缩放，输出 512×512 高清头像
- **内容举报**：长按评论可举报（垃圾广告/违法违规/不实信息）
- **关键路径遥测**：阅读器网络/翻译/评论/摘要等失败自动上报，便于排查问题

## 优化

- 全部页面内容顶部对齐（修复 Scroll 内容居中）
- 输入框统一边框样式（浅色模式边界清晰）
- 阅读器精选/最新 Tab 选中态改为品牌红色
- 个人资料页：用户名改为只读展示（后端约束）

## 修复

- 个人资料保存报 invalid input（请求体与服务端 schema 对齐）
- 头像选择失败（媒体库 URI 需经 fd 读取）
- 会员/方案页内容从中间开始（垂直对齐修复）
