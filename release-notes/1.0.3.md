# 极客译读 1.0.3

## 新增

- **AI 摘要卡片**：文章详情页展示 LLM 生成的摘要 + 精选评论（按 storyId 缓存）
- **侧边栏翻译额度卡片**：实时显示今日已用/总量进度，点击升级 Pro
- **评论树加速**：服务端一次并发解析整棵评论树（/api/reader/tree），替代逐层往返
- **详情页下拉刷新**：重拉文章、评论与摘要
- **原生 Toast**：改用系统 toast，顶部展示，错误/成功红白区分
- **HN 拉取加速**：支持 URL 前缀代理（HACKER_NEWS_API_URL）+ 直连回退

## 优化

- 文章详情内容顶部对齐（修复 Scroll 居中）
- 正文/译文字间距提升阅读体验
- 译文改用富文本渲染（保留分段/链接）
- 设置页语言/译文选择修复

## 修复

- 设置保存"请检查输入内容"（服务端不支持的键只存本地）
- 语言页 Radio 选择不稳定
- 增量构建产物导致启动黑屏（发布前 clean 全量重建）

## 说明

- 翻译额度按设备（安装 ID）计算，每日重置
- 列表标题/正文翻译不消耗额度；评论区翻译消耗额度
